# 🎰 로또 번호 생성기 (ch3_lotto)

인공지능과디지털사고 실습 과제로 제작된 **Streamlit 기반 로또 번호 자동 생성 웹 애플리케이션**입니다.

---

## 📌 주요 기능
- **🎲 로또번호 생성**: 버튼 클릭 시 1~45 범위 내에서 중복 없는 6개 번호를 무작위 추첨 및 정렬하여 출력
- **📜 최대 5개 세트 저장**: 생성 버튼을 연속으로 클릭 시 최근 추첨한 번호가 **최대 5개 회차**까지 화면에 누적 표시
- **🎨 로또 공 공식 색상 구현**:
  - 🟡 **1 ~ 10번**: 노란색
  - 🔵 **11 ~ 20번**: 파란색
  - 🔴 **21 ~ 30번**: 빨간색
  - ⚪ **31 ~ 40번**: 회색
  - 🟢 **41 ~ 45번**: 녹색
- **🔄 초기화 기능**: 생성된 모든 기록을 지우고 초기 상태로 되돌리기

---

## 🛠️ 기술 스택 (Tech Stack)
- **Language**: Python 3.x
- **Framework**: Streamlit
- **Deployment**: Streamlit Community Cloud
